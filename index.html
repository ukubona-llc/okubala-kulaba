//   node mus.mjs build            -> writes music.ndjson
//   node mus.mjs q 'k=edge felt=bII-I'      -> filter records (AND of key=value; dotted keys ok; ~= is substring)
//   node mus.mjs next V7          -> next-token distribution from a state
//

// Pentad (index.md V): tension -> release -> tension ... -> I'. Edge records ARE next-token prediction.

const OUT = "music.ndjson";
const NAMES = ["C","C#","D","Eb","E","F","F#","G","Ab","A","Bb","B"];
const cents = r => 1200 * Math.log2(r);
const rec = [];
const put = o => rec.push(o);

// II. 12TET is a biased sample of the harmonic series: err = how far partial n sits from nearest 12TET pitch.

Source: this session. The Air taught the vocabulary; here it is turned on a piece from the teenage and 30s listening years. The course was taken at 43, and the analysis was done at 46.

I. Engine: the opening stack

E3-G3-C4-A4

Pitch classes C, E, G, A. As a vertical chord it is C6/E or Am7/E, and the bass and context decide the name. Read in E minor it is better heard as a tonic with two non-chord tones, ♭6 (C) and 4 (A), pressing over E–G. The literal label is Em(add11, ♭13). "E11♭13" survives only as shorthand for "i with ♭6 and 4 pressing in", because it claims a 7th and 9th that are not there.

Corrections made on the way: G3→C4 is a perfect 4th, E3→C4 is the minor 6th (the ♭13), and G3→A4 is a major 9th. Resolving C→B while holding A gives Em(add11). Resolving A→G while holding C gives C/E, not Em♭13.

Only the bass moves in chords 1→2→3, then again in 4→5→6. F♯, C and A are held as a common-tone cluster while the roots underneath are permuted: E, E♭, E, E♭, D. The F♯ dropping to F♮ at chord 7 flips the color toward A minor.

The Phrygian flavor lives in the inner voice: F→E over a held D bass is a ♭6→5 half step, the voice-leading of a Phrygian cadence (iv6→V). The bass itself has no half-step cadence there.

III. Permutation: B7 in the melody

The goal is V7 of E minor. The melody circles B with C as an upper neighbor (B–C–C–B), and D♮ against D♯ is a chromatic inflection. Pitch content B, C, D♮, D♯, F♯, A looks like B7(♭9,♯9) only if collapsed into one instant. Spread across the phrase, each tone enters, leans and resolves. This is Chopin, not flamenco: the ♭9 and ♯9 are dissonances that move, not sonorities that stay.

IV. Decode: why the first chord was the thesis

E–G is the tonic frame. C (♭6) and A (4) are the two tones that must discharge. C→B (♭6→5) is the payoff, returning as the upper neighbor on B over V7. A→G (4→3) returns as the 7th of B7 and falls by implication into Em. B is also the 5th of Em, so the top voice barely moves while everything below it does the work.
